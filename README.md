# 영어 세특 스페셜 (0929 seteuk-special)

고등학교 영어과 세부능력 및 특기사항(세특) 작성을 지원하는 웹앱입니다. 말하기와 쓰기 산출물 중심의 관찰 메모를 2022 개정 교육과정 영어과 성취기준(공통영어1/2, 영어Ⅰ/Ⅱ 등 209건 포함 총 3,294건)과 직접 연결하고, 생성된 세특의 인용 오류, NEIS 바이트, 기재금지 표현을 실시간으로 검증합니다.

## 핵심 기능과 차별점

1. **영어과 활동 유형별 관찰 메모 템플릿**:
   - **말하기·발표 / 에세이·쓰기 / 토론·토의 / 영어 프로젝트** 4가지 템플릿을 제공해 수업 중 관찰한 영어 산출물, 어휘·담화 전략, 피드백 수정 과정을 바로 구조화합니다.
   - 선택한 2022 개정 영어과 과목에 맞는 검증된 성취기준 코드를 자동으로 추천해 연결합니다.
2. **2022 개정 성취기준 원문 검증 (`verifyDocument`)**:
   - 교육부 고시 제2022-33호 기반 3,294건(초 611, 중 704, 고 1,979) 데이터와 대조해 지어낸 코드(`FAKE`)나 왜곡된 진술문(`MISMATCH`), 학교급 불일치(`LEVEL`)를 즉시 경고합니다.
3. **NEIS 바이트 계산 및 기재금지 표현 실시간 검사**:
   - 한글 3바이트, 영문·숫자·공백 1바이트, 내부 줄바꿈 2바이트(끝 줄바꿈 제외) 기준으로 1,500바이트(진로 2,100바이트) 한도와 안전 권장 구간(1,350~1,480B)을 표시합니다.
   - 공인어학시험(TOEIC/TOEFL 등), 교외 수상, 상용 플랫폼·AI 상호명(ChatGPT, 파파고, 유튜브 등), 학생 실명·주어 서술, 비격식 종결어미를 자동 점검합니다.
4. **학생 개인정보(PII) 로컬 격리 및 AI 전송 전 가명화**:
   - 학생 명단, 활동 기록, API 키는 외부 DB 없이 브라우저 `localStorage`에만 저장합니다.
   - Gemini API 호출 시 본인 무료 등급 키(BYOK)만 사용하며, 전송 전 학생 이름·학번·연락처를 `[학생]`, `[학번]` 토큰으로 자동 치환합니다.
5. **엑셀(.xlsx) 및 CSV 일괄 내보내기**:
   - 수식 인젝션 방어가 적용된 엑셀(`.xlsx`)과 UTF-8 BOM `.csv` 파일로 검증 상태와 바이트 수를 함께 내려받을 수 있습니다.

## 교사용 빠른 사용 안내

1. **API 키 설정**: 우측 상단 `[API 키]`(설정) 버튼에서 [Google AI Studio](https://aistudio.google.com/app/apikey) 무료 키를 입력합니다. (`gemini-2.5-flash` 또는 `gemini-2.5-flash-lite` 선택, 공용 PC에서는 사용 후 삭제 버튼 클릭)
2. **학생 및 과목 선택**: 상단 `[학생 관리]`에서 학생을 등록하고, 작업할 2022 개정 영어 과목(`공통영어1`, `영어Ⅰ` 등)을 고릅니다.
3. **관찰 기록 작성**: 좌측 패널에서 `말하기·발표`, `에세이·쓰기`, `토론·토의`, `영어 프로젝트` 템플릿을 눌러 관찰 내용과 성취기준을 저장합니다.
4. **AI 생성 및 검증**: `[Gemini 세특 생성]`을 누른 뒤 우측 에디터에서 NEIS 바이트, 기재금지 표현, 성취기준 원문 검증 결과를 확인하고 다듬습니다.
5. **내보내기**: 상단 `[엑셀]` 또는 `[CSV]` 버튼으로 저장한 뒤 NEIS에 입력합니다.

## 로컬 실행 및 검증 명령

```bash
npm install
npm run dev          # 개발 서버 (http://localhost:5173)
npm run build        # TypeScript 검사 + 프로덕션 빌드
npm run test:verify  # Python verify.py vs TS 검증 모듈 회귀 테스트
```
